# Vendored license texts

License texts for shipped components whose source in this repo doesn't carry
its own license file. `tools/build.sh` combines these with the licenses already
in the tree into `THIRD-PARTY-LICENSES.txt` in every build.

| File | Component | Taken from |
|---|---|---|
| `godot-4.7.2/LICENSE.txt`, `godot-4.7.2/COPYRIGHT.txt` | Godot Engine 4.7.2 (the executable) and every library compiled into it | godotengine/godot @ `4.7.2-stable` (ed1daf0) |
| `mesa.txt` | Mesa NIR/SPIR-V/DXIL compilers in Godot's D3D12 renderer (Windows only; not in Godot's COPYRIGHT.txt) | Generated by `tools/mesa_notice.sh` from godot-nir-static `25.3.1-3` |
| `kiss_fft.txt` | kiss_fft (in `native/miniaudio_mic`) | mborgerding/kissfft @ e5e3fac: `COPYING` + `LICENSES/BSD-3-Clause` |
| `miniaudio.txt` | miniaudio (in `native/miniaudio_mic`) | License section at the end of `native/miniaudio_mic/miniaudio.h` |
| `wiggly-appendage-2d.txt` | WigglyAppendage2D (`addons/wiggly_appendage_2d`) | Tameno-01/GodotWigglyAppendage2D @ 5e017b9: `LICENSE` |
| `godot-lip-sync.txt` | Godot lip sync (`UI/Lipsync stuff/godot-lip-sync`) | Malcolmnixon/godot-lip-sync @ 21f26c7: `LICENSE` |
| `pixelorama.txt` | PSD import (`Scripts/Misc/PSD_parser.gd`) and the blend-mode shader (`Scripts/Shaders/BlendModes.gdshaderinc`) | Orama-Interactive/Pixelorama @ b644d17: `LICENSE` |
| `glsl-color-spaces.txt` | Color space functions in `Scripts/Shaders/BlendModes.gdshaderinc` | tobspr/GLSL-Color-Spaces @ 2eaf53f: `LICENSE`, with the "(c) 2015 tobspr" line from `ColorSpaces.inc.glsl` (the LICENSE leaves the holder blank) |
| `open-sans.txt` | Open Sans (`Scripts/Fonts/OpenSans-Medium.ttf`) | googlefonts/opensans @ bd7e376: `OFL.txt` |

When bumping Godot, replace `godot-<version>/` with the new tag's files and
update `NIR_TAG` in `tools/mesa_notice.sh`; the "Regenerate Mesa notice"
workflow then pushes the new `mesa.txt` to the `mesa-notice` branch.
